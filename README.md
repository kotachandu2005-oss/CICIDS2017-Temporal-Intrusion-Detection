# CICIDS2017 Temporal Intrusion Detection Using 1D CNN

## Project Overview
An Artificial Neural Networks project that uses a One-Dimensional Convolutional Neural Network (1D CNN) to classify network traffic as benign or malicious using CICIDS2017.

## Objectives
- Preprocess network-flow data.
- Train an SGD baseline and a 1D CNN.
- Evaluate accuracy, macro-F1, attack recall, and confusion matrix.
- Analyze the model's performance under temporal distribution shift.

## Technologies
Python, Google Colab, Pandas, NumPy, Scikit-learn, TensorFlow/Keras, Matplotlib, and Seaborn.

## Dataset
Official source: https://www.unb.ca/cic/datasets/ids-2017.html

Dataset configuration: https://huggingface.co/datasets/lacg030175/CICIDS2017

## How to Run
Open `CICIDS2017_Temporal_1D_CNN.ipynb` in Google Colab and run its cells in order. Follow the notebook's dataset-loading instructions.

## Results
The notebook includes baseline and CNN evaluation metrics, a confusion matrix, and training graphs.
